🛡️ MBF 2026 Kredit — Első beállítás

Kövesd az alábbi lépéseket az alkalmazás Firebase-hez való csatlakoztatásához.

1

Firebase projekt létrehozása

Nyisd meg a Firebase Console-t és hozz létre egy új projektet.

→ Megnyitás: console.firebase.google.com

Kattints az „Add project" gombra, adj nevet a projektnek (pl. MBF2026Kredit), majd kattints a „Create project" gombra.

2

Email/jelszó bejelentkezés engedélyezése

A projekt létrehozása után: Authentication → Sign-in method → Email/Password → Enable → Save

3

Firestore adatbázis létrehozása

Firestore Database → Create database → Start in production mode → Válaszd: europe-west1 → Done

4

Firebase Storage engedélyezése (fájlfeltöltéshez)

Ha szeretnéd, hogy a tagok PDF-et vagy fotót töltsenek fel a publikációikhoz: Storage → Get started → Production mode → europe-west1 → Done

Ezután a Storage Rules fülén cseréld le a szabályokat:

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /publications/{userId}/{allPaths=**} { allow read: if request.auth != null; allow write: if request.auth != null && request.auth.uid == userId; } } }
5

Firestore biztonsági szabályok beállítása

Firestore Database → Rules fülre kattints, töröld a meglévő tartalmat, majd másold be az alábbit:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth != null; } match /activities/{actId} { allow read, write: if request.auth != null; } } }

Kattints a „Publish" gombra a szabályok érvényesítéséhez. Ha már közzétetted a szabályokat korábban, frissítsd őket ezzel az új verzióval, majd publikáld újra — a „Mentési hiba: Missing or insufficient permissions" hibaüzenet általában erre utal.

6

Webalkalmazás hozzáadása és konfiguráció másolása

Project Overview → „</>" (Web app) gomb → adj nevet (pl. MBF Web) → Register app. Ezután megjelenik a firebaseConfig objektum — másold be az alábbi mezőbe:

Ezzel az email címmel regisztrálva automatikusan admin jogosultságot kapsz.

📧 Email értesítők (opcionális, de ajánlott)

Ha szeretnél emailt kapni új regisztrációs igényekről, regisztrálj az EmailJS.com oldalon (ingyenes, 200 email/hó). Ezután: Email Services → Add New Service → Gmail, majd Email Templates → Create New Template. A sablon tartalma szabadon formázható, a következő változók érhetők el: {{nev}}, {{email}}, {{szervezet}}.

GitHub Pages-hez: Kattints a „Letöltés" gombra — egy konfigurált index.html fájlt kapsz, amit feltölthetsz a GitHub repódba. A felhasználóknak nem kell beállítást elvégezniük.
